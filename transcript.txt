● Good choice using splice。

  ★ Insight ─────────────────────────────────────
  - users は const 宣言なので users = users.filter(...)
  と再代入するとコンパイルエラーになる。splice
  は配列の中身を変更するだけで参照を変えないため const と共存できる
  - findIndex → splice は1回の走査で完結。filter
  は新配列をヒープに確保するのに対し、splice はその場で詰める —
  ここでは誤差だが、大きな配列では差が出る
  ─────────────────────────────────────────────────
